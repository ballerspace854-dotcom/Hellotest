# Pawzi — 20 remade static ads

Twenty distinct 1080 × 1350 PNG ads for owners of active dogs with IVDD on crate rest.

- `statics/`: the 20 finished PNG ads.
- `editable/`: matching SVG artwork. Keep `assets/` beside this folder so the images and original logo load when editing.
- `contact-sheet.pdf`: all 20 ads on five pages.
- `copy-index.csv`: editable copy and review source references.
- `index.html`: an offline gallery; open it after unzipping.
- `sources.md`: exact customer quote attribution and asset sources.

All 20 use the original downloaded Pawzi logo as an image asset. The added design uses Pawzi crimson #C5263B, white and near-black. Ten ads use actual page review excerpts or the page's Mochi customer story; four use new illustrative photo scenes as requested. No new buyer identities or invented customer photos are presented.

The Mochi before-and-after uses unaltered frames from the videos labelled Mochi on the live page, plus the attributed owner story and an individual-results qualifier. The offer ad reflects the page's $99 single-pad price at creation; update it if the offer changes.
